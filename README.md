# Valhalla (video game created with Unity)


This project was developed as part of a university project at Hochschule Mittweida.

The goal of the project was to develop and implement the audio system for a video game and to create its sound design and music.


## Project Work
- Development and implementation of the audio system in Unity
- Programming of audio-related functionality using C#
- Integration and control of sound effects and music
- Production and editing of sound effects
- Composition and production of the soundtrack


## Documentation
Project documentation and additional material can be found in the `docs` directory.
